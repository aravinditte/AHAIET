# API (base http://127.0.0.1:8000)
All errors: {"error":{"code","message","detail"}}.
- GET /api/health -> {status:"ok",service,version,db_ok}
- GET /api/capabilities -> live checks: db_ok, upload limits/formats, preprocessing (pillow, opencv bool, profiles), ocr {tesseract{available,path,traineddata{lang,available,prefix},reason}, kraken{available,reason}, status}, corpus {status,passages,by_language,words,reason}, morphology {status,reason}, translation {status, verified_reference, per_profile {<profile>: {status, verified_reference, engine, evaluation_state, model_version, engines[]}}, reason}, languages.
- GET /api/languages -> biblical_hebrew + biblical_aramaic (separate, profile_defined) + 8 future profiles as unsupported/not_available.
- GET /api/models -> the artifacts/manifests/models.json entries, with each translation entry enriched by LIVE artifact state derived from the disk + model card: artifact_state (not_provisioned | provisioned_missing_files | trained_but_not_evaluated | evaluated), ok, missing[] (the exact missing pieces), model_version, artifact_sha256, chrf_pp (only when the evaluation harness recorded one), selection. The manifest alone never proves readiness.
- POST /api/uploads (multipart file) -> {id,format,width,height,size_bytes,sha256}; 400 invalid_image / unsupported_format / upload_too_large / image_too_many_pixels. Validation is by content (Pillow), never extension.
- GET /api/uploads/{id} -> stored image bytes for preview; 404 upload_not_found.
- POST /api/ocr {upload_id, language_profile?, preprocessing_profile? ("conservative"|"enhanced"), psm?} -> 200 {request_id,status,original_ocr_text,uncertain_spans[{text,conf,line,left,top,width,height}],mean_confidence,word_count,ocr_engine,ocr_lang,ocr_profile,ocr_profile_note,psm,preprocessing{profile,steps},language,processing_time_ms} when a real engine exists; 503 ocr_unavailable when no engine is provisioned; 422 empty_transcription when the engine recognises no text; 400 unknown_preprocessing_profile for a bad profile name (checked once OCR runs).
- POST /api/translate {text, source_language?, corrected_source_text?} -> TranslationResponse fields: request_id,status,detected_language,selected_language,script,original_ocr_text,corrected_source_text,english_translation,translation_method,source_references,uncertain_spans,warnings,model_versions,processing_time_ms, plus additive fields populated when a trained local model produced the output: engine ("moses"|"marian"; "verified_reference" for a corpus match), model_version, artifact_sha256, coverage {source_tokens,known_tokens,coverage_ratio,oov_words[]}. Resolution order: (1) verified corpus match in the selected profile -> 200 with translation_method="verified_reference" and source_references[{passage_id,reference,book,language_profile,match_type (exact|normalized),source_edition,translation_edition,license,provenance,source_text,english_text}] (response shape for this path is unchanged apart from the additive fields, which stay null except engine); (2) the per-profile selected trained engine (selection: recorded chrF++ from the evaluation harness wins; no metrics -> Moses before Marian as the documented default) run as a local subprocess — moses (AHAIET_MOSES_CMD) with the shared tokenizer applied, or marian-decoder (AHAIET_MARIAN_DECODER_CMD) with the exported decoder config; out-of-vocabulary source words are listed in warnings and in coverage.oov_words, never silently dropped; 504 translation_timeout when the decoder exceeds AHAIET_TRANSLATION_TIMEOUT_S (default 120s); an artifact that is provisioned but incomplete yields 503 naming the missing pieces; (3) 503 translation_model_unavailable — the detail distinguishes "corpus present but no match" from "no corpus imported", names any provisioned-but-incomplete artifacts, and a variant candidate (match_type="normalized_variant") may be attached as variant_candidate with a warning; a variant is never returned as the translation. 400 empty_text.
- POST /api/retrieval {text, language} -> {match: <source_reference>|null, variant_candidate: <source_reference+warning>|null}. Searches only the given profile's index. 400 unsupported_language / empty_text.
- POST /api/morphology {text, language} -> {language_profile, adapter, words:[{word, status: found|not_found, entries:[{surface,lemma,strongs,morph_code,word_language,reference,source_edition}]}]}. Hebrew and Aramaic adapters read separate word indexes (morphhb H/A-coded words of their own profile's passages). 503 corpus_unavailable when no corpus word index is imported; 400 unsupported_language / empty_text.
- POST /api/process {upload_id, language_profile?, preprocessing_profile?, psm?} -> creates a jobs row, runs the OCR stage and stores the full OCR result (text, uncertain spans, preprocessing report) in the job; {job_id,status,stage,error}. With no OCR engine the job ends status=failed, stage=ocr, with the reason recorded.
- GET /api/jobs/{id} -> job row; 404 job_not_found. GET /api/jobs/{id}/result -> {job_id,status,stage,error,result}.
- GET /api/history -> {history:[...]} (rows are written by /api/process). DELETE /api/history/{record_id} -> {deleted:id}; 404 history_not_found.
