# Architecture
Monorepo: frontend (Next.js/TS) -> typed client (frontend/src/lib/api.ts) -> FastAPI backend -> modular services -> SQLite + content-hash file storage.
Backend modules: api/routes.py (all /api routes), core/config.py (env-typed Settings), core/errors.py (AppError -> {error:{code,message,detail}}), schemas/models.py (Pydantic contracts incl. TranslationResponse), services/preprocessing (Pillow content validation, pixel/byte limits, MAX_IMAGE_PIXELS guard), services/ocr (tesseract_adapter via shutil.which+subprocess; kraken_adapter via import check), services/language (profile suggestion; script-alone invariant), services/translation (manifest-driven; moses_adapter subprocess, marian_adapter runtime check), services/{morphology,retrieval,verification} (typed not_provisioned interfaces), storage/db.py (sqlite3, MIGRATIONS list + schema_version table).
Uploads are stored as <sha256><ext-from-detected-format>; user filenames never enter a path. Upload fetch validates the id is 64 hex chars before globbing (traversal-safe).
Models load from artifacts/manifests/models.json; an entry counts only if status=provisioned AND its artifact path exists on disk.
