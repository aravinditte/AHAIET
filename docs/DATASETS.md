# Datasets
Part 1: NO datasets are bundled, downloaded, or listed — artifacts/manifests/datasets.json has an empty datasets list and reference_passages is empty.
Rules for later parts: every corpus needs a named edition, a licence that permits the intended use, provenance (source + retrieval date), partition (train/dev/test) recorded in the manifest, and a checksum. Invented or unattributed "scholarly" entries must never be inserted. A reference translation may be returned only for a verified, identified corpus match (Part 3).
