# Model evaluation
No OCR or translation model has been measured yet, so no scores are reported anywhere in this repository.
Evaluation must report separately, each with dataset, partition, date, and the exact command recorded in docs/BUILD_STATE.md: transcription accuracy (CER/WER from backend/app/evaluation/metrics.py over the fixtures in training/ocr/fixtures/), language-identification accuracy, translation quality on a held-out partition, and reference-match precision. The measurement runner is training/evaluation/evaluate_ocr.py; see docs/VERIFICATION.md for how to run it and what output to expect. Fabricated or copied scores are prohibited by docs/PROJECT_CONTRACT.md.
