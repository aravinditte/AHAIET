# Training
Nothing has been trained yet. training/ holds dataset preparation, OCR fixture/evaluation tooling, and per-area notes (datasets, preprocessing, alignment, smt, nmt, ocr, evaluation, configs).
Planned work (not implemented): a Moses SMT baseline (WSL2 path), a Marian NMT fine-tune, and possibly a Kraken OCR fine-tune; the engine with the best independently measured score per language profile wins — SMT is not assumed to beat NMT or vice versa. Training must use free/open-source data with recorded licences (docs/DATASETS.md); synthetic data must never be passed off as authentic scholarly data. The imported corpus partitions (Genesis blocks for train/validation, Daniel held out as test) exist so training and evaluation never share near-identical verses.
